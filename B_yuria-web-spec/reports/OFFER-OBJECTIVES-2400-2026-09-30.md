# 2400 分主目標：出牌模型與推薦目標驗證

日期：2026-09-30。**依使用者修正，主要研究門檻改為 2400 分，1500 作對照。正式引擎先保留；研究模型仍不部署。**

逐卡出牌模型對候選牌的統計吻合較好，但本次 2400 主測試的改善很小，且部分推薦受到亂數影響。最大平均分目標在研究假設下有較好的分數訊號，仍不能稱為真實牌局分數提升。

| 組別 | 推薦主要排序 | 達標機率欄位的門檻 |
| --- | --- | ---: |
| 主測試 target2400 | 最大化 2400 達標率，同率比較平均分 | 2400 |
| 對照 target1500 | 最大化 1500 達標率，同率比較平均分 | 1500 |
| 對照 expected2400 | 最大化平均分 | 2400（只作觀察指標） |

目標覆寫只在研究腳本；原始 28 場仍是使用 3000 目標遊玩的紀錄，沒有改寫或重新標記成 2400／1500 真實局。正式網頁的預設目標與引擎程式未修改。

## 2. 新出牌模型是否改善同一目標的推薦？

表中差為「逐卡研究模型的推薦減現行模型推薦」，在研究假設出牌世界以獨立亂數評估。相同推薦的差為 0，先平均每場五個決策再以整場 bootstrap 10000 次。單位是**歷史狀態的平均決策差**，不是完整五回合牌局總分差。

主測試的達標率差在這次探索性區間略高於 0，但幅度很小，而且尚未涵蓋完整 Monte Carlo 誤差／時間相關性。不能據此宣告真實 2400 達標率提高；均分區間仍包含 0。

不能把不同目標的表格分數差當成「expected 比 target2400 多得 1.74 分」。每一列是各自目標下的新舊出牌模型差，不是目標之間的直接效果。

## 3. 主測試多種子排名穩定度

只對 target2400 主種子改選的 6 個狀態追加 seeds 20260931、20260932；每次同樣 8192 次模擬，三張候選全部重算，而不是只比較原先兩張。

- 現行模型首選三種子一致：5／6。
- 研究模型首選三種子一致：4／6。
- 新舊模型都穩定、且三種子持續改選：3／6。
- 其餘 3 個至少有一種子回到相同推薦；不能全部視為可靠改選。

持續改選的三個狀態（序號為原始 JSON 陣列位置）：

| 原始序號／回合 | 現行推薦 | 研究推薦 |
| --- | --- | --- |
| 28／2 | 隱者／紅 | 正義／藍 |
| 22／1 | 惡魔／紫 | 塔／紅 |
| 12／3 | 隱者／藍 | 太陽／紫 |

穩定度只針對主種子改選子集，沒有量測全部 140 個狀態的三種子穩定率，也沒有對 1500／expected 完整做多種子實驗。

## 4. 達標率目標與平均分目標是否選不同牌？

同一出牌模型將目標由 2400 threshold 改為 expected：現行模型 28／140 次首選不同，研究模型 26／140 次不同。差異都在前四回合。

28 個第五回合精確狀態中，兩個目標選擇剛好相同；兩種出牌模型也逐項得到相同第五回合結果。這只是這批狀態的特性，不代表所有最後一手中「最大平均分」與「最大達標率」必然一致。

要衝 2400，主要排序仍應使用 2400 達標率；要提高常見的平均分，應使用 expected 目標。兩種目的分開呈現，保留最高預期分數及達標率，不承諾一定達標。
